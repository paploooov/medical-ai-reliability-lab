# Licensing status

An MIT license is optional, not a prerequisite for publishing research code on GitHub. A public repository without a software license does not automatically grant broad rights to reuse, modify or redistribute its code.

MIT would be a reasonable permissive choice for the project's original software if the rights holder chooses to grant those permissions. No license grant has been added yet. Dataset rights are separate: MedMNIST lists PneumoniaMNIST under CC BY 4.0. Dataset examples, derived figures and model weights should not be assumed to acquire an MIT license merely because a code license is added. Source attribution remains in the README.
