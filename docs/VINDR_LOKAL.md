# VinDr-PCXR lokal auswerten – sechs Schritte

1. **Python installieren.** [Python 3.12](https://www.python.org/downloads/) in 64 Bit installieren; unter Windows „Add Python to PATH“ aktivieren. Unterstützte Anleitung: Windows x64 und Mac mit Apple-Chip. Für alte Intel-Macs fehlen passende aktuelle PyTorch-Pakete; diese Kombination ist nicht geprüft. Etwa 10 GB freien Platz und möglichst 8 GB RAM vorsehen.

2. **Repository herunterladen.** Auf [GitHub](https://github.com/paploooov/medical-ai-reliability-lab) „Code → Download ZIP“, entpacken, Terminal/PowerShell im entpackten Projektordner öffnen. Dort müssen `scripts/`, `configs/` und die 30 `.pt`-Dateien in `reports/original_512/thoraxis_30/checkpoints/` liegen. Daten und Projekt in lokalen Ordnern außerhalb von OneDrive/iCloud/Dropbox speichern.

3. **Abhängigkeiten installieren.** Windows: `py -3.12 -m venv .venv-vindr`, dann `.\.venv-vindr\Scripts\python.exe -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu`, dann `.\.venv-vindr\Scripts\python.exe -m pip install -r requirements-vindr-local.txt`. Mac: `python3.12 -m venv .venv-vindr`, dann `.venv-vindr/bin/python -m pip install -r requirements-vindr-local.txt`. Danach braucht die Auswertung kein Internet und lädt keine Gewichte nach.

4. **Nur Testdaten lokal herunterladen.** Bei [PhysioNet, VinDr-PCXR 1.0.0](https://physionet.org/content/vindr-pcxr/1.0.0/) Zugangsvoraussetzungen erfüllen und DUA akzeptieren. Nur den Ordner `test/` (1.397 DICOMs, veröffentlicht etwa 5,7 GB) und `image_labels_test.csv` herunterladen. Beides nebeneinander in einen separaten lokalen Datenordner legen; eine heruntergeladene ZIP dort entpacken. Keine Trainingsbilder, Bounding-Box-Dateien oder komplette Datensatz-ZIP nötig. Erwartet werden benannte binäre Labelspalten wie „No finding“ und „Pneumonia“ sowie `.dicom`/`.dcm`-Dateien. Falls Dateistruktur oder Schema abweichen, stoppt das Skript; keine Daten oder Screenshots davon hierher senden.

5. **Einmal starten.** Windows: `.\.venv-vindr\Scripts\python.exe scripts/run_vindr_external.py --data-dir "C:\lokale_daten\vindr-pcxr" --out ergebnis.json`. Mac: `.venv-vindr/bin/python scripts/run_vindr_external.py --data-dir "/Users/DEINNAME/lokale_daten/vindr-pcxr" --out ergebnis.json`. Den Datenpfad ersetzen. Netzwerk kann getrennt werden. Bestehende Ergebnisdateien werden nicht überschrieben. Während des Laufs gibt es bewusst keine Bildnamen oder Einzelbild-Logs. Grob **10–30 Minuten auf einem normalen Laptop**, bei langsamer CPU/Datenträger länger. Herleitung: Hier benötigten vier künstliche Bilder durch alle 30 Modelle 0,615 Sekunden (ein CPU-Thread); das entspricht etwa 3,6 Minuten reiner Modellrechnung für 1.397 Bilder, ohne DICOM-Laden und Bootstrap. Kein gemessener VinDr-Lauf.

6. **Nur `ergebnis.json` zurückgeben.** Sie enthält zusammengefasste Fallzahlen und Modellkennzahlen, die 5×5-Kontraste, getrennte Seed-/Split-Streuung, Gruppen-Bootstrap-Intervalle und Modell-Hashes. Bilder, Labeldateien, IDs und Einzelvorhersagen werden nicht exportiert. Bei Abbruch erscheint nur eine allgemeine Fehlermeldung; dann diese Meldung weitergeben, keine Daten. Modelle, Schwellen oder Regeln nicht nachträglich anpassen und nicht mit anderen Varianten erneut auswerten.

**Stand der Vorbereitung:** Protokoll zuerst unter `fdd4ff5` auf GitHub eingefroren; [Festlegung](THORAXIS_VINDR_PROTOKOLL.md), [Konfiguration](../configs/thoraxis_vindr_external.json), [Skript](../scripts/run_vindr_external.py). Sieben synthetische Tests bestanden: 8/12/16 Bit, MONOCHROME1, Fenster/LUT, Padding, fehlerhafte Eingaben, Auswahlregeln, Datenschutz und vollständige Aggregatausgabe. Gemeinsamer Encoder und direkte Berechnung aller 30 Modelle lieferten identische Logits. Der synthetische Acht-Bilder-Durchlauf einschließlich 2.000 Bootstraps dauerte 6,990 Sekunden. Tests liefen unter Linux; Windows/Mac sind hier nicht praktisch geprüft. Echte Daten wurden nicht geladen. Patienten sind nicht sicher verknüpfbar; bei fehlenden StudyInstanceUIDs wird der publizierte Studien-Proxy ausdrücklich ausgewiesen. Dies begrenzt die Unsicherheitsaussage.
